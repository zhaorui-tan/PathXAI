# Sample execution

The repository contains the final SO1/Core and SO4/Full outputs for TCGA-OR-A5LL. Both use all six pinned source slides (DX1–DX5 and TS1; 11,156,338,264 bytes, about 10.39 GiB), the same ordered 20 candidate ROIs, Refined D1 segmentation and the documented adrenal gland / adrenocortical site. The example notebooks display captured run progress and reports; inference was executed through the same tutorial Python API, not inside those notebook cells. Use the main `PathXAI_report.ipynb` for fresh inference.

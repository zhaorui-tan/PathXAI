# Sample execution

The repository contains the final PathXAI(core) and PathXAI outputs for TCGA-OR-A5LL. Both use all six pinned source slides (DX1–DX5 and TS1; 11,156,338,264 bytes, about 10.39 GiB), the same ordered 20 candidate ROIs, Refined D1 segmentation and the documented adrenal gland / adrenocortical site. The main notebook and the two variant notebooks retain their actual inference cell outputs, including the pipeline progress and generated report. The HTML links point to the output of each corresponding notebook run.

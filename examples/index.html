What these examples show

These are recorded patient-level executions, compared with the historical D1 demo and an existing aligned reference report. They are not a clinical accuracy benchmark. The known anatomical site was supplied before inference; no reference diagnosis was supplied. All five slides entered the candidate pool; the final ROIs came from two slides, which are displayed in the reports. The original report wording and image bytes are preserved. The notebook records retain actual outputs; repetitive heartbeat messages and feature-progress refreshes were condensed, and machine-specific paths were replaced for reading.

The completed notebooks can also be previewed directly in the GitHub repository. Use the main tutorial notebook in that repository to run your own data.
